# Линейная регрессия: от аналитического решения до регуляризации и переобучения

Проект посвящён изучению линейных моделей для задачи регрессии — от классической линейной регрессии до регуляризованных моделей (Ridge, Lasso, ElasticNet). В рамках проекта реализованы собственные версии алгоритмов с нуля, проведено сравнение с реализациями из `scikit-learn`, а также исследовано влияние нормализации признаков и полиномиальных преобразований на качество моделей.

**Задача:** предсказание стоимости аренды квартир в Нью-Йорке на основе набора признаков (количество спален, ванных комнат, наличие определённых удобств и т.д.)

---

## Цель проекта

- Понять математику линейной регрессии (нормальное уравнение, градиентный спуск).
- Реализовать модели «с нуля» и убедиться, что они дают результаты, близкие к sklearn.
- Исследовать влияние регуляризации (Ridge, Lasso, ElasticNet) на переобучение.
- Показать, как полиномиальные признаки позволяют моделировать нелинейные зависимости.
- Научиться правильно сравнивать модели с помощью MAE, RMSE и R².

## Что реализовано

### 1. Теория
### Аналитическое решение линейной регрессии

Линейная регрессия предполагает, что целевая переменная является линейной комбинацией признаков:

$$\hat{y} = \mathbf{w}^T \mathbf{x} + b$$

Для нахождения оптимальных весов минимизируется среднеквадратичная ошибка (MSE):

$$\text{MSE}(\mathbf{w}) = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2$$

В векторной форме задача записывается как:

$$\min_{\mathbf{w}} (\mathbf{y} - X\mathbf{w})^T (\mathbf{y} - X\mathbf{w})$$

Аналитическое решение (нормальное уравнение):

$$\mathbf{w} = (X^T X)^{-1} X^T \mathbf{y}$$

### Регуляризация

Для борьбы с переобучением в функцию потерь добавляется штраф за сложность модели:

$$\min_{\mathbf{w}} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2 + \lambda R(\mathbf{w})$$

- **L2-регуляризация (Ridge):** $R(\mathbf{w}) = \|\mathbf{w}\|_2^2 = \sum_j w_j^2$
  - Аналитическое решение: $\mathbf{w} = (X^T X + \lambda I)^{-1} X^T \mathbf{y}$
  - Уменьшает веса, но не обнуляет их

- **L1-регуляризация (Lasso):** $R(\mathbf{w}) = \|\mathbf{w}\|_1 = \sum_j |w_j|$
  - Не имеет аналитического решения, решается координатным спуском
  - Обнуляет неважные веса, выполняя отбор признаков

- **ElasticNet:** комбинация L1 и L2

### 2. Кастомные реализации (`LinearRegression.py`)

| Класс / функция | Что делает |
|------------------------------------|-------------------------------------------------|
| `LinearRegressionCustom` | Analytical / Batch GD / SGD |
| `RegularizedLinearRegression` | Ridge, Lasso, ElasticNet + gradient clipping |
| `MinMaxScalerCustom` | Нормализация в [0, 1] |
| `StandardScalerCustom` | Стандартизация (μ=0, σ=1) |
| `MyPolynomialRegression` | Полиномиальная регрессия + coordinate descent |
| `r_squared`, `mean_absolute_error_custom`, `root_mean_squared_error_custom` | Метрики |

SGD сделан **детерминированным** через `np.random.RandomState(seed)`.

1. Обычная линейная регрессия (custom vs sklearn).

## Основные результаты

| Модель | R² train | R² test | Комментарий |
|--------------------------------|----------|---------|--------------------------------------|
| Linear / Ridge / Lasso (raw) | 0.58 | **0.57** | Лучшее качество на 22 признаках |
| ElasticNet (sklearn) | 0.43 | 0.42 | Слишком сильная регуляризация |
| Модели + MinMaxScaler | 0.56 | 0.56 | Небольшое ухудшение |
| Модели + StandardScaler | 0.31 | 0.30 | Learning rate не перекалиброван |
| Linear Polynomial | 0.52 | 0.41 | **Сильное переобучение** |
| **Lasso Polynomial** | 0.52 | **0.52** | Самая стабильная модель |
| Naive mean / median | 0.00 / −0.05 | — | Бейзлайн |

**Выводы:**
- На исходных 22 признаках регуляризация почти не меняет качество — модель и без неё не переобучается.
- На полиномиальных признаках (65 сильно коррелирующих) без регуляризации происходит классическое переобучение (разрыв train/test ≈ 0.11).
- Lasso + coordinate descent практически полностью убирает этот разрыв за счёт обнуления лишних весов.
